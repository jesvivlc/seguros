## Reutilizar open source antes de implementar
Antes de implementar una función nueva (UI, animación, lógica, exportaciones, etc.), busca en GitHub repositorios open source con más de 1.000 estrellas y licencia MIT, Apache 2.0 o BSD que resuelvan algo parecido. Úsalos solo como referencia de enfoque y reimplementa adaptado a nuestro stack (vanilla JS + Supabase). No copies código ajeno. No incorpores código ni dependencias con GPL/AGPL o sin licencia declarada. No aplicar a lógica de sustituciones, RLS de Supabase, normativa ni permisos por rol. Al terminar, dime qué repos has revisado, con su licencia, y qué has aprendido de cada uno.
